# Neural Networks and Deep Learning

My coursework collection for the Neural Networks and Deep Learning course in Andrew Ng's Deep Learning Specialization by DeepLearning.AI.

NumPy fundamentals, logistic regression, shallow neural networks, and deep neural networks.

The repository includes relevant helper code, available reference notes, and supporting diagrams. Large datasets, pretrained models, media, notebook checkpoints, and duplicate starter copies are excluded.

## Using these materials

Open the notebooks in Jupyter and use the imports in each notebook to set up its environment. The assignments span different TensorFlow/Keras versions, so an individual notebook may need its original course environment. Notebooks that load external datasets, pretrained weights, or media require those files at the paths used in the notebook. Obtain those assets from the corresponding course resources before running them.

The saved code and existing notebook outputs are preserved. The notebooks have not been rerun as part of preparing this repository.
